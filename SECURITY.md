# Security Policy

## Supported Versions

This repository is part of an educational Java project where unit testing, Maven, and GitHub Actions will be evaluated.

security updates are applied to this current version of the project.

## Reporting a Vulnerability

Any detected vulnerabilities should be immediately reported in private through GitHub's security reporting features where available.

Do not expose any security vulnerabilities before review. 

## Security Practices

This project uses:

GitHub security features to identify potential vulnerabilities.
Dependabot to monitor dependencies.
A .gitignore file to exclude sensitive files.
Branch protection to reduce unintended changes.
